# Sprite Flight

**Sprite Flight** is a simple 2D arcade game made with Unity.  
The player controls a small spaceship flying inside a confined area while avoiding moving obstacles. The goal is to survive as long as possible and achieve a high score.

🕹 **How to Play**  
- Hold the left mouse button to move the ship toward the cursor.  
- Avoid collisions with obstacles and screen boundaries.  
- Your score increases over time.

🎮 **Features**  
- Simple and responsive flight controls.  
- Randomly generated obstacles with different sizes and speeds.  
- Minimal UI with score display, restart, and exit buttons.

📦 **Build**  
The project can be built using Unity for desktop platforms such as Windows and macOS.
